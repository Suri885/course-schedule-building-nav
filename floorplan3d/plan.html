核对说明

1. 两座楼都不是方正矩形：D 座是「锯齿台阶状」——北边 3 部楼梯（楼梯①②③）与东端空调机房、2 部电梯向北凸出，南边 D阶-202 / D阶-201 与东段逐级错落；C 座是「阶梯斜边梯形」——西侧 4 段、东北角 1 段 35° 斜边。
2. D 座北排为 D-307 → D-301，嵌三处楼梯；西列为 D-308 / D-309 / D-310，D-312 位于中南部，D3 教师休息室位于 D-313 南侧、东纵廊西侧。
3. D 座东端（从 C 座走过来的落脚处）：电梯①/② 并排贴在北端、门朝南，正前方留出一大块电梯厅空地（实景里的那片大理石地面），南接北横廊；空调机房在电梯西侧，机房再往西是强电间 / 弱电间两小格，都开门朝走廊。
4. D 座卫生间不是「并排三间」：四处（D-311 东侧、D-313 东侧、D-314 东侧、西南 D-310 东南）统一成「卫 ｜ 前室（小空地）｜ 卫」——前室一通到底、男女卫的门开在前室两侧且正对，和实景照片一致；男女卫中间不再放残卫，残卫单独在三小间那排（开水间 → 残卫 → 强电间）。前三组女卫在西、男卫在东；西南那组按原图是男卫在西、女卫在东，前室从南横廊北上。四组都能从走廊直接走进前室。
5. C 座西北是一大块上空凹口（灰斜纹）；绿色虚线是原图的疏散通道，只有它走得到的地方才可通行。核心筒自西向东是：空调机房（仅 2.2 m 宽的窄条）→ 出口楼梯 → 电梯①②（中间横向电梯厅，可走）→ 强弱电间 → C3 教师休息室。
6. C 座核心筒明确画出 电梯① / 电梯②（对角 × 标记）与电梯厅；东列为 C-301 / C-302 / C-303 / C3 教师休息室，C阶-201 已按原图收小到 13.7 × 11.7 m。
7. 落进斜边里的房间（男卫、女卫、消防强电间）与门厅走廊都按斜线截短，不会穿出外墙；每间房的门都开向公共走廊或前室。
8. 房间标签按宽高自动缩放；狭窄设备间采用竖排，阶梯教室分两行。模型尺寸按照片比例估算，不能替代测绘尺寸。
9. 方向对照：这张俯视图「上＝北」，站在 D-301 面朝 D-307（向西）时右手边是北排教室，左手边才是卫生间、其他教室和通道。三维漫游里的朝向与这张图一致（俯仰、左右都没有镜像）。
10. D-314 西侧是一条南北向走廊（不是房间）：北端从北横廊拐进来，一路向南穿过 D3 教师休息室东侧、D阶-201 东侧，南端是安全出口。走廊西墙上依次是开水间 → 残卫 → 强电间三小间，门都朝东开向这条走廊——按实景照片，它们是从走廊拐进去的，不是排着面朝教室。
11. C/D 两座之间现在有两条连廊：连廊 A 在 D 座东端（北横廊东端，电梯厅以南）接 C 座北廊「通往D座」口；连廊 B 从 D-314 西侧走廊南端的安全出口出楼，向东接 C 座 C阶-202 西北的安全出口楼梯，进门后是一条小通道，向南接 C 座西横廊。两条连廊都是「平段 + 进 C 座前 3.2 m 起坡 0 → 0.9 m」，两侧带护栏。
12. D-312 出口楼梯与 D阶-202 旁的安全出口是同一个疏散节点：楼梯口朝南正对一条东西向走廊（夹在 D阶-202 北墙与 D-312 之间），这条廊往东顶到 D阶-201 西墙，再北上接 D阶-201 西廊，然后沿北廊到 D3 教师休息室东侧的安全出口。所以「男女卫 → D阶-202 旁 → D阶-201 → D3 教师休息室 → 安全出口 → 连廊」整条路是通的，D阶-201 不会再被空地封住。
