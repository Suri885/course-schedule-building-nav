# course-schedule · 课表小程序

一个纯本地的微信小程序课表工具：拍照或粘贴课表文字，自动识别成课表；附带备忘录、提醒、第二课堂与任务打卡等校园常用功能。

## 功能

- **课表主页**：按周展示课程，支持切换周次（默认 16 周）、查看单节课详情。
- **智能统一导入**：上传课表照片 → 自动识别 → 生成可编辑预览 → 写入课表。
  - 离线模式（默认）：选图后手动粘贴/输入课表文字，本地解析器 `utils/extract.js` 逐行提取课程名、星期、节次、教师、教室、授课周次。
  - 云模式（可选）：开通微信云开发并部署 `cloudfunctions/ocr` 后，走腾讯云 OCR 自动识别，`utils/grid.js` 按坐标把文字块重排成表格行。
- **手动添加课程**：`pages/add-course`，支持课程名、教师、教室、星期、起止节次、周次。
- **日程表排序**：顶层默认展示本周；本周视图下今日任务置顶，其余仍按周一 → 周日顺序排列。
- **两种添加入口**：
  - 右下角总加号 → **批量添加课程**（保存后停留本页连续录入，星期/节次/周次自动保留），适合开学一次性录入整学期课表。
  - 每一天卡片右上角的加号 → **添加当天事项**，日期自动带入，可选「课程 / 会议 / 讲座 / 其他」，按时段或按节次填写。
- **提醒（独立板块）**：`pages/remind`，与日程表分离。
  - 事务分为「已确认」与「未确认」，打开默认进入已确认的待完成事务。
  - 按剩余天数显示红 / 黄 / 绿三色紧急度，默认一周红、两周黄、一个月绿，可在页内 ⚙ 自定义天数阈值。
  - 事务可填写截止日期 + 时刻（精度到某日某时），支持数周至数月的长周期倒计时，显示剩余天数与小时。
  - 已确认且倒计时变红的事务会自动置顶到首页（`pages/home`）并显示为红色条框。
  - 「已确认」「未确认」两个页签各有独立的加号，新增时状态由页签自动决定，不用手选。
  - 可标记为「固定项目」：不设截止日期、长期有效，列表中用蓝紫色标注，不参与红黄绿倒计时。
  - 已确认区顶部有独立的「📌 置顶区」，任一条都可以点 📌 置顶，置顶后同时出现在工作台首页；置顶区与固定项目区都可折叠。
  - 已完成列表里的任一条都可以直接删除。
- **错题与背诵**：`pages/review`（今日复习 + 总资料库）、`pages/review-edit`（编辑）、`pages/review-mask`（涂抹遮盖）、`pages/review-study`（复习）。
  - 按艾宾浩斯遗忘曲线排期：当天 → 1 → 2 → 4 → 7 → 15 → 30 天 → 2 → 3 → 4 个月 → 半年；答「记住了」推进一档，答「没记住」回到明天。
  - 学完的资料可点「已完全学会」移出每日复习队列（总资料库里标注「已完全学会」，可随时取消回到队列）。
  - 支持文字、图片、视频三种载体；图片可用画笔涂抹遮盖（涂过即变白），笔刷分特细/细/中/粗，并支持双指捏合缩放 + 按钮缩放后再细涂；复习时先看遮盖图再做对照，实现填空式背诵。
  - 图片可 OCR 提取文字到答案区（需开启云识别，未开启可手动输入）。
  - 总资料库支持按资料名称 / 内容 / 答案做关键字检索，空格分词需全部命中。
- **备忘录**：`pages/memo`，纯记录不勾选、不做待办。
  - 大输入框随手记，支持插入图片（最多 9 张，选图后保存到本地私有目录，重启不丢）。
  - 仍可把某条备忘「贴到课表」的某个时段，作为课表里的便签显示。
- **第二课堂**：`pages/second-class` 与 `pages/section-detail`、`pages/module-tasks`、`pages/task-record`，用于记录活动与模块任务完成情况。
  - 加分记录分「待确认 / 已确认」：新建记录只是本人登记，需在学校正式系统申请通过后回到任务页点「确认加分」才计入得分；待确认记录用琥珀色标注，已确认用绿色标注。
  - 进度按各任务细则**逐项核算**：目标 = 各条细则上限之和，剩余 = Σ(每条上限 − 该条已得)，所以「总进度」与明细完全对得上；办法规定的模块/板块满分作为参考值另行列示。

```

pages/
  home/                        课表主页
  index/                       总览入口（FAB 菜单）
  add-course/                  手动添加课程
  import/                      智能统一导入（拍照 / 粘贴）
  memo/                        备忘录
  remind/                      提醒
  second-class/                第二课堂
  section-detail/              模块详情
  module-tasks/                模块任务
  task-record/                 任务打卡记录
utils/
  courses.js                   课程数据与工具函数
  extract.js                   本地课表解析器（正则 + 分块）
  grid.js                      OCR 结果按坐标重排成表格

  secondClass.js               第二课堂数据
cloudfunctions/ocr/            可选：腾讯云 OCR 云函数
```

## 本地运行

1. 用微信开发者工具「导入项目」，选择本目录。
2. 在 `project.config.json` 里把 `appid` 换成你自己的小程序 AppID（或用测试号）。
3. 直接编译即可运行，默认不需要任何后端或云服务。

## 开启拍照自动识别（可选）

1. 开发者工具顶部「云开发」→ 开通 → 复制环境 ID，填到 `config.js` 的 `CLOUD_ENV`。
2. 右键 `cloudfunctions/ocr` →「上传并部署：云端安装依赖」。
3. 云开发控制台 → 云函数 `ocr` → 配置 → 环境变量，添加 `TENCENT_SECRET_ID` / `TENCENT_SECRET_KEY`（腾讯云 API 密钥，不要写进代码）。
4. 腾讯云控制台单独开通「文字识别 OCR」服务。
5. 把 `config.js` 里的 `OCR_ENABLED` 改为 `true`，重新编译。

## 开发说明

- 全部数据存放在小程序本地缓存（`wx.setStorageSync`），不联网、不收集用户信息。

- `project.private.config.json` 为本机开发者工具私有配置，已被 `.gitignore` 忽略。
